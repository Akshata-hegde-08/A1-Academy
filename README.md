# 📚 A1 Academy – Engineering Made Easy

Your First-Year Engineering Companion at PES University

A1 Academy is a student-focused educational platform designed specifically for first-year engineering students at PES UNIVERSITY 

It aims to bring essential academic resources, study materials and learning support together in one convenient place, making the first year of engineering more organized, accessible and easier to navigate.

## 🎓 About A1 Academy

The first year of engineering  introduces students to various subjects, laboratory sessions, academic cycles and examination patterns.

Finding the right study materials and keeping everything organized can sometimes be challenging.

A1 Academy aims to make this easier.

It provides a centralized platform where Pesuvians can explore subject-wise learning resources, prepare for examinations, access laboratory materials and find useful academic guidance.

Whether you are revising concepts, preparing for internal examinations or working on laboratory assignments, A1 Academy aims to make your academic journey more convenient.

## ✨ What Can You Find Here?

### 📖 Handwritten Notes

Access organized, unit-wise handwritten notes, study summaries and important derivations to support conceptual understanding.

### 📝 Previous Year Questions

Explore previous-year question papers and structured exam-preparation resources to understand examination patterns and practise effectively.

### 🧪 Lab Resources

Find laboratory-related materials for:

- Chemistry
- Physics
- Python
- MATLAB

Including records, graphs, programs and viva preparation resources.

### 📚 Reference Materials

A dedicated space for engineering textbooks, standard formula references and additional learning materials.

### 💡 Study Tips

Explore useful study strategies, examination guidance, frequently asked questions and placement-related insights.

## 🌟 Key Highlights

- Subject-wise and cycle-wise organization.
- Multiple academic resource categories in one place.
- Easy navigation between interconnected pages.

## 🚀 Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
